gse_fork patches to ingame_overlay
====================================

Upstream repository: https://github.com/Nemirtingas/ingame_overlay
Upstream commit:     0f9305c10e572b51d17447c5e4d2872337b13ab5

Purpose
-------
Expose the active DXGI swap chain pointer through a new virtual method
GetDXGISwapChain() on RendererHook_t so that callers (steam_overlay.cpp)
can query IDXGISwapChain3 for authoritative color-space information
(e.g. DXGI_COLOR_SPACE_RGB_FULL_G2084_NONE_P2020 = HDR10,
       DXGI_COLOR_SPACE_RGB_FULL_G10_NONE_P709   = scRGB/FP16).

Lifetime / thread-safety notes
-------------------------------
The stored pointer is the same IDXGISwapChain* that the game passed to
Present / Present1, and it stays valid until ResizeBuffers destroys the
swap chain (at which point _ResetRenderState(Reset) is called and new
render targets are created on the next Present, overwriting the member).
In the Removing state the pointer is explicitly cleared to nullptr.
Callers must QueryInterface to IDXGISwapChain3 before use and release the
resulting interface pointer when done.
